   local Studio place and connect the Rojo plugin to `localhost:34872`. Alternatively

2. Confirm `ReplicatedStorage > Shared`, `ServerScriptService > Server`, and
   `StarterPlayer > StarterPlayerScripts > Client` exist, plus the prototype floor/spawn.
3. Press Play in default Preview. Confirm the red horseshoe is carried in front with both hands,
   the HUD shows `Coins: 0` and an explicit warning that Preview progress is not
   saved. Inspect server `StorageMode = "Preview"`, `DataReady = true` and
   `DataStatus = "Preview"`; check Output for startup/storage errors.
4. Stand at the spawn: the metals at z=-24 and Coin at (0,1.5,24) must remain
   visible and no coins, inventory counts or discoveries change.
5. Approach Bolt (-20,1.5,-24), Can (0,1.5,-24), Gear (20,1.5,-24).
   At range level 0, regardless of equipped skin, within 12 studs the winning client should see a metal ghost fly to the magnet

   metal sale value is not paid at pickup. From fresh discovery, the third distinct
   metal also grants the 3-discovery Book bonus of 10 coins. Collect one of each,
   move away from all pickups, then press `Sell all`: inventory becomes empty,
   the sale adds 9 coins and the wallet is 19 (10 Book + 9 sale). Discovery stays
   at 3/15. Inspect server state separately from cosmetic receipts.
6. Stay by a collected object: no duplicate reward before its 5-second respawn.
   Inspect its `Available` and `LifecycleId` attributes. Each respawn changes
   the token and allows one new reward. Continuous proximity collects every respawn.
7. Reset during attraction. No ghost/magnet leaks or Output errors; coins, inventory and the equipped magnet remain
   for the session and collection resumes with the new character.
8. Stop and restart Play. Coins/inventory return to zero, discoveries become empty and the magnet returns to Starter

## Malformed/replay/out-of-range requests

12. After sync, disconnect Rojo temporarily. In Studio only, insert a temporary
    `LocalScript` named `RemoteAbuse` under `StarterPlayer > StarterPlayerScripts`.
    Before Play, select `StarterPlayerScripts > Client > main` and set its
    `Enabled` property to false to disable automatic scanning for this isolated test.
    Insert the following code. This keeps rejection tests independent of legitimate
    nearby pickups. Start Play
    and inspect the server's player Coins/inventory attributes and Output.

```luau
local Players = game:GetService("Players")
local RS = game:GetService("ReplicatedStorage")
local player = Players.LocalPlayer
local request = RS:WaitForChild("Remotes"):WaitForChild("RequestCollect")
local folder = workspace:WaitForChild("Collectibles")
local target = folder:WaitForChild("Can")
local root = player.Character or player.CharacterAdded:Wait()
root = root:WaitForChild("HumanoidRootPart")
root.CFrame = CFrame.new(0, 4, 50) -- outside the Can pickup range
task.wait(1)
local before = player:GetAttribute("Coins")
local beforeCan = player:GetAttribute("Inventory_can")
local beforeBolt = player:GetAttribute("Inventory_bolt")
local beforeGear = player:GetAttribute("Inventory_gear")
local function expectState(canCount)
    assert(player:GetAttribute("Coins") == before, "Collection granted coins")
    assert(player:GetAttribute("Inventory_can") == canCount, "Unexpected Can count")
    assert(player:GetAttribute("Inventory_bolt") == beforeBolt, "Unexpected Bolt count")
    assert(player:GetAttribute("Inventory_gear") == beforeGear, "Unexpected Gear count")
end
local token = target:GetAttribute("LifecycleId")

request:FireServer() -- missing args
request:FireServer("not-an-instance", 123) -- wrong types
request:FireServer(workspace.PrototypeFloor, "unregistered")
request:FireServer(target, string.rep("x", 10000)) -- oversized token
request:FireServer(target, token) -- correct token, but out of range
task.wait(1)
expectState(beforeCan)

root.CFrame = target.CFrame + Vector3.new(0, 3, 0)
task.wait(1)
request:FireServer(target, token .. "-stale") -- right position, stale token
task.wait(0.5)
expectState(beforeCan)
request:FireServer(target, token) -- one legitimate claim
for _ = 1, 100 do request:FireServer(target, token) end -- flood/replay
task.wait(1)
expectState(beforeCan + 1)

task.wait(5)
local newToken = target:GetAttribute("LifecycleId")
assert(newToken ~= token, "Token not rotated on respawn")
request:FireServer(target, token) -- previous lifecycle cannot claim new spawn
task.wait(0.5)
expectState(beforeCan + 1)
request:FireServer(target, newToken)
task.wait(0.5)
expectState(beforeCan + 2)

task.wait(5)
local humanoid = player.Character:FindFirstChildOfClass("Humanoid")
humanoid.Health = 0
task.wait(0.5)
request:FireServer(target, target:GetAttribute("LifecycleId")) -- dead/reset character
task.wait(0.5)
expectState(beforeCan + 2)
print("Manual hostile-request checks finished; inspect SERVER Output too")
```
